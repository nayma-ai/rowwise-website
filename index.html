06 / Good to know

A few details,
before you start.

More questions? Talk to us

Which sources are in Preview?

libSQL / Turso, Elasticsearch, OpenSearch, Amazon Redshift, Databricks and Trino are read-only Preview connectors. Amazon DynamoDB read-only support is qualified on macOS; it remains Preview on Windows and Linux. Snowflake and BigQuery are available without a source Preview label. Capabilities vary by engine.

How does the MCP server work?

Connect a source in Rowwise, then enable the server in Settings → MCP. Add its local HTTP endpoint to your compatible client. It exposes currently connected sources, discovered schemas, bounded reads and query tools. It starts off each time Rowwise opens and is read-only by default. Write tools require explicit opt-in, and saved read-only connections remain protected.

What can my AI assistant see?

Rowwise’s built-in AI sends your prompt, relevant schema metadata and applicable saved definitions to your configured provider, without query result rows. MCP is different: its tools return schema and query results to your connected client. That client may send them to its model provider. Credentials remain managed by Rowwise.

Can AI change my database?

Ask uses read-only queries. AI changes in the Query editor are drafts you review and run yourself. MCP is read-only by default; enabling write/delete tools lets clients make supported changes without per-query approval. Saved read-only mode still applies.

Can I connect Neon or Supabase?

Yes. Use the PostgreSQL connection type with your provider’s host, database and credentials. Neon and Supabase are PostgreSQL-compatible services, rather than separate query engines.

Do I need an AI subscription?

AI features use your own OpenAI, Anthropic, Gemini or compatible API key, or a local model through Ollama. Provider charges are separate; Rowwise adds no AI markup. Non-AI database workflows work without an AI key.

What happens after the 14-day trial?

A license key is required to reopen your workspace. Your connections, saved queries and history remain on your computer. At stable launch, Personal ($49, two devices) and Pro ($69, three devices) are one-time licenses for one person with 12 months of updates. Your last eligible version keeps working after update coverage ends. Checkout stays closed until the stable Mac release is ready.

What does offline use include?

First activation requires an internet connection. After activation, the signed license can be verified locally. Work with local databases and files offline; cloud AI providers and remote databases need their own network access. A local Ollama model is an option for AI without a cloud provider.

Which platforms can I use?

The current macOS beta is one universal download for Apple Silicon and Intel. The app and DMG are signed with an Apple Developer ID and notarized by Apple. Windows and Linux remain Preview. Preview installer availability is separate from macOS. Contact support for Windows or Linux Preview access.
