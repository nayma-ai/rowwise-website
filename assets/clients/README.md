# MCP client icons

These assets identify compatible client products and are bundled locally. No client-icon CDN requests are made at runtime. Names and marks belong to their respective owners; this is not a partnership listing. SVG geometry and image contents are unchanged.

- Claude Code: the official Claude mark from https://claude.com/icon.png (Claude family branding).
- Cursor: official app-icon SVGs from https://cursor.com/marketing-static/favicon.svg and https://cursor.com/marketing-static/favicon-light.svg, linked from https://cursor.com/brand.
- OpenCode: official square marks from the `anomalyco/opencode` repository, `packages/console/app/src/asset/brand/opencode-logo-{dark,light}-square.svg`, linked through https://opencode.ai/brand.
- Codex: the actual icon from the OpenAI-published Codex extension, https://marketplace.visualstudio.com/items?itemName=openai.chatgpt. The OpenAI developer-site favicon is not used.

Dark/light variants follow the website theme without recoloring the source assets. Visible names provide accessible link labels; the repeated image labels are decorative. Each client links to its MCP setup documentation.
