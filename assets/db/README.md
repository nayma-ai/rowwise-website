# Database logos

Bundled SVG assets; no network requests at runtime. Displayed as monochrome masks inheriting the UI foreground color.

- PostgreSQL, MariaDB, SQLite, Redis, MongoDB, DuckDB: Simple Icons 16.33.0, https://github.com/simple-icons/simple-icons (CC0; license included).
- MySQL, Oracle and SQL Server: Devicon v2.17.0, https://github.com/devicons/devicon (MIT; license included). Oracle uses the O symbol from the original wordmark, with its SVG viewport cropped to that glyph.
